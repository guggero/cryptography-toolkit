Explanation

An extended key contains a version, depth, parent fingerprint, child number, chain code, and either a compressed public key or private key data (00 followed by a 32-byte scalar). Base58 encoding adds a four-byte checksum. Paste an xpub or xprv to inspect it, or change a field to update the encoded key. The checksum updates automatically when other fields change; you can also edit it to see what an invalid checksum does.
