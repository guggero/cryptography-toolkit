Tapscript Debugger

Explanation

This page executes a taproot script spend with the real script engine of btcd (compiled to WebAssembly) and lets you step through it op code by op code.

It knows the three tapscript op codes that BIP 448 proposes to add to Bitcoin with a soft fork:
  • OP_TEMPLATEHASH pushes a hash of the spending transaction that commits to its outputs, but not to the outputs being spent.
  • OP_CHECKSIGFROMSTACK checks a signature over a message from the stack instead of the transaction.
  • OP_INTERNALKEY pushes the taproot internal key of the output being spent.
None of them is active on any Bitcoin network. Each one can be switched between the three states a node can be in, to see what a soft fork changes: before activation the op codes are OP_SUCCESS op codes, which make a script valid without executing it.

This is experimental code for a proposal that may change. Do not use it to build anything that holds real funds.
